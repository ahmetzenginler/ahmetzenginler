# Ahmet Zenginler

Software Engineering student (4th year) at **Burdur Mehmet Akif Ersoy University**. I study in Bucak, Burdur and live in İzmir.

I build tools and pipelines for 3D and games: software that takes a model through a measured, repeatable process and hands
back something a game engine can use.

## Projects

The source code of these projects is private. Each link goes to a page with screenshots and a description.

| Project | What it does |
|---|---|
| [**AutoRig**](https://github.com/ahmetzenginler/autorig-overview) | One humanoid character in, a Unity package and an Unreal project out. Own rigger with a dedicated finger module, skinning quality control on ten hard poses, a separate skeleton and key bindings for each engine. |
| [**Asset Atölyesi**](https://github.com/ahmetzenginler/asset-atolyesi-overview) | Graduation project. A sketch or text becomes an optimized, game-ready 3D asset in Unity, with time, cost and quality measured at every step. |
| [**Asset Showcase Studio**](https://github.com/ahmetzenginler/asset-showcase-studio-overview) | Desktop app that turns a 3D model into a promo video and Asset Store images without opening Unity. |
